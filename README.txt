SKDH V8 — EDITABLE LINK DIRECTORY

To change a destination:
1. Open links.js in Notepad or edit it directly on GitHub.
2. Replace only the URL inside quotation marks for the relevant item.
3. Save and commit the change to GitHub.
4. When GitHub is connected to Netlify, the live site updates automatically after deployment.

Keep links.js beside index.html. Keep the assets folder beside them. Do not rename the keys before each colon.
Recommended publishing workflow: upload this complete folder to GitHub and connect the repository to Netlify.
